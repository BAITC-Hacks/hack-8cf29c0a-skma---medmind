# Frontend

Все рабочие экраны используют backend. Переменная `VITE_USE_MOCK` больше не используется; отсутствие сервера приводит к состоянию ошибки с повторной загрузкой.

## Запуск

Из папки `frontend` (Node.js 22.18+):

```sh
npm ci
npm run dev
```

Backend должен работать на `http://127.0.0.1:8000`; Vite проксирует `/api`.
В production нужен reverse proxy или `VITE_API_BASE_URL`, заданный при сборке.
Единый запуск в контейнерах описан в корневом README.

## Экраны

- `/orders`: серверные рекомендации, ручные заказы, корректировки, утверждение, отклонение, удаление и CSV. Изменение количества возвращает заказ на согласование. Утверждение не отправляет заказ поставщику.
- `/products`: общий каталог, поиск, категории, сортировка, серверная пагинация. Товар и текущий остаток сохраняются одной транзакцией. Для товаров без текущего снимка показывается последний месячный остаток с датой. Цена — себестоимость, неизвестная цена не подменяется нулём. Связанные с историей товары защищены от удаления. ZIP-комплекты поставщиков загружаются с предварительной проверкой и отдельным подтверждением замены.
- `/sales`: реальные документы, даты, поставщики, категории, отгрузки и возвраты. Поиск, сортировка, пагинация, общие счётчики и график операций вычисляются сервером; CSV включает всю отфильтрованную выборку. Цена реализации отсутствует во входных данных, поэтому выручка не рассчитывается.
- `/dashboard`: показатели заказов, риски, месячный спрос и сезонность выбранного расчёта. Отсутствие прогнозов отображается явно. Ссылка на риск открывает карточку заказа.
- `/settings`: параметры расчёта, сроки поставки, MOQ, кратность, настройки ассистента. Пересчёт доступен здесь и в шапке; статус обновляется автоматически.
- `/assistant`: серверные диалоги, файлы, анализ и действия по заказам. Для ответов требуется настроенный доступ к модели.

История продаж и каталог показывают текущие входные данные; дашборд и заказы привязаны к выбранному расчёту. После изменения источников выполните пересчёт. Демо-фикстуры используются только автоматическими тестами и не подключены к рабочим экранам.

## Проверки

```sh
npm test
npm run build
npm run lint
```

Проверки API выполняют настоящий HTTP-адаптер с подменой транспорта. Серверные интеграционные тесты каталога, продаж, экспорта и аналитики находятся в `backend/tests/test_workspace.py`.
